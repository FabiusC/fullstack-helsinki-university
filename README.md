# fullstack-helsinki-university

Monorepo de ejercicios del curso Full Stack Open.

## Folder Structure

This repository is organized by course part:

- `part-0`: sequence diagrams for the introductory exercises.
- `part-1`: first React exercises and small apps.
- `part-2`: state, forms, data fetching, and multiple React apps.
- `part-3`: backend exercises with Node.js and Express.
- `part-4`: blog list backend with testing and user authentication.
- `part-5`: frontend tests and end-to-end testing for the blog app.
- `part-6`: state management exercises with Redux, React Query, and Context API.

Each folder contains the code, configuration, and notes for that part of the course.
